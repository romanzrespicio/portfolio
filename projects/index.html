League of Legends: Gold Statistical Analysis

DSC80 project using Oracle’s Elixir professional match data to study how total gold relates to damage, farm, and other outcomes. I built an end-to-end pipeline with cleaning, feature engineering, and EDA; used hypothesis tests and permutation analyses (including missingness on goldat25); and trained classification models with cross-validation, improving a baseline decision tree with a Random Forest and engineered jungle-focused features—then shared results on GitHub Pages and in the GitHub repository.
